## Brand & Style

### 브랜드 비전과 사용자 정의
건설사 본사 공무팀 및 현장 관리 임원진을 대상으로 하는 현장별 공정률(Progress Rate) 및 기성(Earned Value Management) 모니터링 대시보드 시스템입니다. 수백 억 단위의 공사 계약, 하도급 정산, 자재 납품, 마일스톤 진척도를 한눈에 검토하고 이상 징후를 조기에 파악할 수 있는 신뢰성 중심의 정보 환경을 제공합니다.

### 디자인 톤앤매너
- **신뢰와 권위 (Reliable & Authoritative):** 고밀도 엔터프라이즈 환경에 적합한 단정하고 체계적인 그리드 기반 레이아웃을 사용합니다.
- **기능적 미니멀리즘 (Systematic Modern Corporate):** 불필요한 장식과 과도한 그라디언트를 배제하고, 데이터 테이블과 시각화 지표 중심의 깔끔한 정보 설계를 지향합니다.
- **인지 부하 최소화:** 상태 지표(정상/주의/점검)는 색상에만 의존하지 않고 명확한 텍스트 라벨 및 시맨틱 심볼과 병행 표기하여 즉각적이고 오차 없는 의사결정을 보장합니다.

## Colors

### 컬러 팔레트 전략
본 디자인 시스템은 엔터프라이즈 거버넌스와 금융·원가 모니터링 환경에 적합한 색상 구조를 채택합니다.

- **Primary (`#2563EB` - Smart Blue):** 핵심 액션 버튼, 활성 탭 인디케이터, 링크, 선택된 상태 등 주요 상호작용 지점에 한정적으로 적용하여 시선 집중도를 극대화합니다.
- **Secondary (`#0F172A` - Slate Dark Navy):** 글로벌 헤더, 메인 내비게이션 바, 주요 타이틀 영역에 적용하여 견고하고 안정적인 인상을 형성합니다.
- **Tertiary (`#1E293B` - Slate Navy Medium):** 카드 헤더 텍스트, 보조 내비게이션, 차트 기본 축 및 구분선 텍스트에 적용됩니다.
- **Neutral (`#64748B` / Slate 계열):** 본문 보조 텍스트, 메타데이터 라벨, 테이블 셀 보더(`#E2E8F0`), 배경 채우기(`#F8FAFC`) 등 계층별로 정밀하게 배치합니다.

### 상태 지표 색상 시스템
현장 공정률 및 기성 집행률 평가 시 단일 색상에 의한 오독을 방지하기 위해 정량 수치 및 텍스트 뱃지와 반드시 병기합니다.

- **정상 (Normal / On-track):** `#10B981` (Emerald Green) - 공정률 달성, 기성 정산 승인 완료
- **주의 (Warning / Lagging):** `#F59E0B` (Amber) - 예정 공정 대비 5% 미만 지연, 기성 청구 차이 발생
- **점검 (Critical / Action Required):** `#EF4444` (Red) - 예정 공정 대비 5% 이상 지연, 안전/원가 이상치 감지

## Typography

### 타이포그래피 원칙
- **Inter 기반의 맑고 객관적인 판독성:** 영문 수치 단위(%, KRW, M, D)와 한글 라벨 간의 베이스라인 정렬이 자연스럽고 화면 밀도가 높은 B2B 대시보드에 최적화되었습니다.
- **수치 데이터 tabular-nums 강제 적용:** 기성금, 계약액, 누적 공정률, 계획 대비 실적 등 모든 통계 수치 표기에는 `font-variant-numeric: tabular-nums` (고정폭 숫자 모드)를 글로벌 적용하여 수직 비교 시 숫자 너비 흔들림 없이 정렬되도록 합니다.
- **위계적 시선 유도:** 대시보드 화면 내 핵심 수치(KPI 메인 지표)는 `numeric-kpi` 28px/700 가중치로 한눈에 읽히도록 하며, 데이터 테이블 셀 본문은 13px/14px로 컴팩트하게 구성하여 한 화면에 표기 가능한 공구별 정보량을 확보합니다.

## Layout & Spacing

### 레이아웃 철학
본 시스템은 PC 웹 데스크톱(1920x1080 및 1440x900 권장 해상도)에 최적화된 고밀도 24/12단 유동형-고정 복합 그리드를 지향합니다. 좌측 LNB(Local Navigation Bar: 240px 고정)와 상단 툴바(64px 고정)를 기본 축으로 하며, 메인 콘텐츠 영역은 잔여 폭에 맞춰 자연스럽게 반응합니다.

### 간격 리듬
- **8px 단위 기반의 4px 서브 스케일 체계:** `space-xs`(4px), `space-sm`(8px), `space-md`(12px), `space-lg`(16px), `space-xl`(24px)로 엄격히 통제합니다.
- **테이블 및 폼 필드:** 행(Row) 높이는 표준 44px, 컴팩트 36px로 유지하며, 셀 내부 좌우 패딩은 `space-md`(12px)을 기준으로 설정합니다.
- **KPI 대시보드 그리드:** 4분할 또는 6분할 균등 그리드 카드로 상단에 배치하며, 카드 간 거더는 `gutter`(16px)을 적용합니다.

## Elevation & Depth

### 깊이감 표현 전략: 정밀한 1px 보더와 섬세한 섀도우
엔터프라이즈 공무 시스템은 시각적 피로도를 낮추기 위해 과도한 드롭 섀도우나 블러 효과를 배제하고, 구조적 보더(Border)와 미세한 음영으로 계층을 구분합니다.

- **Level 0 (기본 배경):** `#F8FAFC` (Slate-50) 캔버스.
- **Level 1 (표준 카드 및 테이블 컨테이너):** `#FFFFFF` 표면 + `1px solid #E2E8F0` 외곽선. 섀도우 없음 또는 `box-shadow: 0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Level 2 (인터랙티브 호버 및 필터 툴바):** `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
- **Level 3 (팝오버, 드롭다운, 상세 공정 툴팁):** `#FFFFFF` 표면 + `1px solid #CBD5E1` + `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)`.
- **Level 4 (모달 및 정산 승인 다이얼로그):** 딤 오버레이 `rgba(15, 23, 42, 0.45)` 위에 배치되며 `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.12)`.

## Shapes

### 형태 언어: 정제된 4px (Soft) 라운드
정교한 도면과 공학적 수치를 다루는 건설업 본사의 특성을 반영하여 과도한 곡률을 배제한 단정하고 이성적인 직사각형 기반의 모서리를 적용합니다.

- **기본 곡률 (`roundedness: 1`):** 버튼, 인풋 필드, 뱃지, 셀렉트 박스, 테이블 셀 태그 등 기본 컨트롤 요소에 일괄 `4px (0.25rem)` 반경을 적용합니다.
- **컨테이너 곡률 (`rounded-lg`):** 대시보드 KPI 카드, 차트 블록, 모달 컨테이너, 메인 테이블 래퍼에는 `8px (0.5rem)` 반경을 적용하여 안정적인 프레임을 완성합니다.
- **알약 형태(Pill) 지양:** 공학적 데이터의 위계와 그리드 정합성을 위해 뱃지나 태그 또한 완전 타원형(Pill)을 쓰지 않고 4px 라운드 사각 뱃지로 통일합니다.

## Components

### 1. KPI 카드 (Summary Metric Card)
- **구조:** 현장명/공구 라벨, 주 지표명, 현재 누적 수치(예: 87.4%), 계획 대비 차이값 뱃지(예: `+2.1%p 정상`), 하단 미니 진행률 바(Progress Track).
- **스타일링:** 흰색 배경, 1px 보더(`#E2E8F0`), 상단 테두리에 상태별 2px 액센트 라인 옵션(정상: `#10B981`, 주의: `#F59E0B`, 점검: `#EF4444`).

### 2. 공정·기성 데이터 테이블 (Data Table & Grid)
- **헤더:** 배경색 `#F1F5F9`, 텍스트 12px Medium `#475569`, 텍스트 정렬은 문자열(좌측), 공정률/금액(우측), 상태 뱃지(중앙).
- **행 스타일:** 고정 행 높이 40px~44px, 행 간 1px 하단 보더 `#E2E8F0`. 호버 시 행 전체 배경 `#F8FAFC` 전환.
- **소계 및 합계 행:** 배경 `#F8FAFC`, 텍스트 볼드 13px 처리 및 상단 2px 더블 보더 적용.

### 3. 상태 뱃지 (Status Badge)
반드시 아이콘 점(Dot) 또는 명시적 텍스트를 함께 표기합니다.
- **정상:** 배경 `#ECFDF5`, 텍스트 `#065F46`, 보더 `#A7F3D0` + 텍스트 라벨 "정상"
- **주의:** 배경 `#FFFBEB`, 텍스트 `#92400E`, 보더 `#FDE68A` + 텍스트 라벨 "주의 (지연)"
- **점검:** 배경 `#FEF2F2`, 텍스트 `#991B1B`, 보더 `#FECACA` + 텍스트 라벨 "점검 요망"

### 4. 필터 툴바 (Filter Toolbar)
- **배치:** 상단 고정 영역, 현장 선택 드롭다운(본사/지사/현장별 멀티 셀렉트), 공기(시작일~종료일 캘린더 픽커), 공종 필터(토목, 건축, 플랜트 등), 기성 차수 선택 셀렉트.
- **컨트롤 요소:** 높이 36px 통일, 배경 흰색, 보더 `#CBD5E1`. 포커스 시 테두리 `#2563EB` 및 아웃라인 링 2px 부여.

### 5. 아코디언 (Accordion - 공종/내역 상세 펼침)
- **패턴:** WBS(작업분류체계) 대공종 클릭 시 중공종/소공종 하위 내역이 슬라이드 다운으로 전개.
- **인디케이터:** 우측 16px 쉐브론 아이콘(`ChevronDown`), 펼침 상태 시 180도 회전 트랜지션(150ms ease).
- **계층 구분:** 하위 레벨 진입 시 들여쓰기 16px(`space-lg`) 적용 및 좌측 1px 가이드라인(`#E2E8F0`) 표시.

### 6. 탭 네비게이션 (Tab Navigation)
- **라인 탭(Line Tab):** 공정 개요 / 기성 실적 / 자재 수급 / 리스크 관리 간 전환. 높이 44px, 활성 탭 하단에 2px `#2563EB` 인디케이터 라인 적용. 텍스트 활성 시 `#2563EB` Bold, 비활성 시 `#64748B` Regular.

### 7. 버튼 및 액션 (Buttons)
- **Primary:** 배경 `#2563EB`, 호버 `#1D4ED8`, 텍스트 `#FFFFFF`, 패딩 8px 16px, 반경 4px.
- **Secondary (기성 마감/다운로드):** 배경 `#FFFFFF`, 보더 `#CBD5E1`, 텍스트 `#1E293B`, 호버 시 배경 `#F8FAFC`.
- **Danger (반려/보완 요구):** 배경 `#EF4444`, 텍스트 `#FFFFFF`.
