# 고의 오류 파일 사용법 — B안

정상 자료 가져오기 후 오류 입력을 거부하고 기존 자료를 유지하는지 확인합니다.

1. 정상 현장공정기성.csv 144행을 가져옵니다.
2. 아래 파일을 하나씩 선택합니다.
3. 오류 이유·위치가 보이고 9월 67.2%·점검 3곳이 유지되는지 확인합니다.

| 파일 | 고의 오류 | 예상 |
|---|---|---|
| 오류_중복키.csv | 2026-09/D를 마지막에 추가, 145행 | 중복 키 거부 |
| 오류_공정률101.csv | 2026-09/A의 actualProgress만 101 | 범위 오류 거부 |
| 오류_공정률빈값.csv | 2026-09/A의 actualProgress만 빈칸 | 필수값 오류 거부, 0 변환 금지 |

1행은 헤더입니다. 공정률 오류는 파일 134행, 중복 추가 행은 파일 146행입니다.

오류 파일은 나머지 열·행을 정상 원본과 동일하게 유지합니다. 앱에서 실제로 거부되는지 확인하기 전에는 앱 테스트 통과로 기록하지 않습니다.
