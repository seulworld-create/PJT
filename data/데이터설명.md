**교육용 가상 데이터입니다. 실제 동일토건의 현장·계약·실적·지연 사유를 나타내지 않습니다.**

- 데이터 ID: dongil-training-20261030-b / 스키마 버전: 2.0 / 개정일: 2026-10-30
- 범위: 현장 A~L 12곳 × 2025-10~2026-09 12개월 = 144행
- 한 행의 뜻: 한 현장의 한 달 월말 상태 / 고유 키: month + siteId
- 초기 조회: 2026-09, 지역·공사 유형·현장 모두 전체
- 출처: B안 확정에 따라 현장별 상황을 먼저 정해 만든 교육용 합성 자료. 실제 회사의 사업 구성·규모·관리 기준이 아님
- CSV: UTF-8 BOM / JSON: UTF-8 / 두 파일은 같은 144행·15개 열

## 파일 사용

1. ZIP을 풀고 CSV 또는 JSON 중 한 형식만 앱에 가져옵니다.
2. 검사·미리보기 후 전체 교체합니다. CSV 다음 JSON을 가져와도 144행입니다.
3. 검증용_오류데이터 폴더는 오류 처리 확인에만 씁니다.
4. 원본을 보존하고 Excel 편집·검증 실험은 사본에서 합니다. month는 YYYY-MM 문자열, siteId는 문자로 읽습니다.

## 집계·판정 규칙

| 항목 | 계산·기준 |
|---|---|
| 현장 공정차이 | 실제공정률 - 계획공정률,단위 pp |
| 상태 | 0pp 이상 정상 / -5pp 초과·0pp 미만 주의 / -5pp 이하 점검 |
| 점검 우선순위 | 공정차이 오름차순, 동점이면 siteId 오름차순 |
| 현장 기성률 | 누적기성액 / 계약금액 × 100 |

월별 계약금액·누적기성액을 여러 달 합쳐 전 기간 총액으로 표시하지 않습니다. 당월기성액이 0인 것은 정상값일 수 있으며 누락값과 구분합니다.

필터는 월·지역·공사 유형·현장입니다. 지역이나 유형을 바꿔 선택 현장이 범위에서 빠지면 현장 선택을 전체로 되돌립니다. 숫자·차트·표·CSV·AI 범위는 항상 같은 필터를 따릅니다.

화면의 상태 판정과 가중 공정률은 교육용 규칙입니다. 동일토건의 공식 관리 기준이나 실제 공정 산정 방법으로 설명하지 않습니다.

## 가져오기 검증

- 15개 열은 모두 필수입니다. 빈 문자열·누락을 숫자 0으로 바꾸지 않습니다.
- 숫자는 유한값·유효 범위를 확인하고 month + siteId 중복을 거부합니다.
- 같은 siteId의 현장명·지역·유형·계약금액·착공일·계약상 준공일은 전 기간 동일해야 합니다.
- 날짜 형식, 착공일 < 계약상 준공일, 월말 기준일이 착공 전이 아닌지 확인합니다.
- 누적공정률·누적기성액의 감소는 본 교육 자료에서는 오류로 처리합니다. 실무 정정·설계 변경은 이번 범위 밖입니다.
- JSON metadata의 schemaVersion 2.0·moneyUnit·progressUnit·requiredFields를 확인합니다.
- CSV에는 메타데이터가 없으므로 이 설명서의 단위와 필드 기준을 쓴다고 안내합니다.
- 정상 원본은 144행입니다. 선택 범위 내보내기는 일부 행일 수 있으므로 모든 CSV를 무조건 144행으로 제한하지 않습니다.
- 월별 누락은 경고하고 확인 가능한 행만 집계했다고 표시합니다. 전월 누락 시 당월기성액은 계산 불가입니다.
- 검증·미리보기 후 전체 교체합니다. 오류·취소 시 기존 정상 자료를 유지합니다.

## AI가 설명할 수 있는 범위

- 현재 필터의 선택 월 원문 행과 프로그램이 계산한 지표를 보냅니다.
- 추이 질문에는 같은 지역·유형·현장의 시작 월~선택 월 요약을 함께 보냅니다. 한 현장 선택 시 해당 현장의 월별 기록도 함께 보낼 수 있습니다.
- 답변에 기준 월·siteId·참고 필드 또는 월별 요약을 표시합니다.
- issueSummary는 '기록된 상황', actionPlan은 '계획된 대응'으로 설명합니다. 원인·완료 여부를 새로 만들어 내지 않습니다.
- contractEndDate는 계약상 일정으로만 안내합니다. 실제 준공 보장·예측, 수금·미수금, 기상 실측은 답할 자료가 없습니다.
- 필터 변경 시 이전 답변을 지우고, 요청 중 범위가 바뀌면 이전 응답을 새 범위에 표시하지 않습니다.
