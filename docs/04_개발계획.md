# 개발 계획 — 현장별 공정·기성 대시보드

## 한눈에 보기

1. EPIC 3개, Story 11개입니다. (기준: EPIC 3개 이하, Story 15개 미만)
2. 순서: EPIC 1(자료 가져오기·필터·현황·추이) → EPIC 2(점검 현장·기록 펼침·CSV) → EPIC 3(AI 질의) → 로컬 전체 검증 → 결과 보고 후 대기.
3. EPIC은 한 번에 하나씩 만들고, 만든 뒤 자동 검사를 돌립니다.
4. 사용자가 브라우저에서 확인했다고 답하기 전에는 완료로 표시하지 않습니다.
5. GitHub 저장과 Vercel 배포는 Story에 넣지 않고, 사용자가 각각 별도로 요청한 뒤 진행합니다.

## Story 표

| 번호 | 사용자가 할 수 있는 일 | 확인할 행동 (브라우저) | 보여야 할 결과 |
|---|---|---|---|
| 1-1 | 4개 페이지 메뉴로 이동하고, 처음 열었을 때 "자료 없음"을 본다 | 앱을 처음 열고 상단 메뉴 4개를 차례로 누른다 | 모든 페이지에 "자료 없음, 자료 가져오기에서 파일을 불러오세요" 안내가 보이고 메뉴가 강조된다. |
| 1-2 | CSV·JSON 파일을 검사하고 미리 본 뒤 적용하거나 취소한다 | 자료 가져오기에서 `현장공정기성.csv` 선택 → "적용". 이어서 `.json` 선택 → "적용". `검증용_오류데이터`의 파일 3개를 각각 선택. 미리보기에서 "취소" | 미리보기에 144행·15/15열 통과가 보인다. 적용 후 CSV와 JSON 모두 "144행으로 교체", 288행이 되지 않는다. 오류 파일 3개는 "n번째 행의 ○○ 열: 이유"가 보이고 "지금 자료는 유지됩니다"가 나온다. 취소하면 현황이 그대로다. |
| 1-3 | 월·지역·유형·현장을 고르고 큰 숫자 4개를 본다 | 현황 요약에서 기준월 2026-09 확인 → 지역 "인천", 유형 "공동주택" 선택 → 지역을 "경기"로 변경 → 기준월 2025-10 선택 | 2026-09 전체: 기성률 67.2%, 계획 73.2%, 실제 71.2%, 공정차이 -2.0pp(보조: 630,700 / 424,063.4 / 28,878.7). 인천·공동주택은 A·G 2곳 기준 숫자로 바뀐다. 선택 현장이 범위에서 빠지면 현장이 "전체"로 돌아가고 안내가 나온다. 2025-10은 당월기성액이 "계산 불가"이고 누적 숫자는 보인다. 현장이 없는 범위는 0%가 아니라 "자료 없음"이다. |
| 1-4 | 선택 월까지의 공정률 추이와 월별 기성 막대를 본다 | 기준월을 2026-09, 2026-03, 2025-10으로 바꿔 차트를 본다. 필터를 바꿔 본다 | 2026-09는 12개월 계획·실제 선과 마지막 점 73.2% / 71.2% / -2.0pp, 막대 마지막 28,878.7, 아래에 7월 364,718.5(57.8%)·8월 395,184.7(62.7%)·9월 424,063.4(67.2%)가 보인다. 2025-10 막대는 "계산 불가"로 0이 아니다. 필터를 바꾸면 차트도 같은 범위로 바뀐다. |
| 2-1 | 점검 현장 순위를 본다 | 현황 요약에서 순위를 보고 월과 필터를 바꿔 본다 | 2026-09 전체: ① D(계획 86.5% / 실제 75.8% / -10.7pp / 기성률 69.4%) ② I ③ K, 위에 정상 6·주의 3·점검 3. 점검 현장이 없는 범위(예: 인천·공동주택)는 "점검 대상 없음" 화면이 나온다. |
| 2-2 | 12개 현장 비교표를 본다 | 현장별 비교표 페이지를 열고, 필터를 바꿔 본다 | 2026-09 전체 12행에 지역·유형·당월 주요 공종·계약금액·누적기성액·당월기성액·기성률·계획·실제·공정차이·상태(글자+색)가 있고 맨 아래에 합계 줄이 있다. J의 7월을 고르면 당월기성액 0.0이 보인다. |
| 2-3 | 행을 펼쳐 기록을 보고, 순위에서 눌러 이동한다 | 비교표에서 D 줄을 눌러 펼친다. 현황 요약으로 돌아가 순위의 D 줄을 누른다 | D 줄 아래에 공사기간(2024-09-02~2027-02-28), "기록된 상황", "기록된 대응 계획"(주간 확인 내용), 계약상 준공일 안내가 보인다. 순위의 D 줄을 누르면 비교표로 이동해 D 줄이 강조되고 열려 있다. |
| 2-4 | 지금 범위를 CSV로 내려받는다 | 2026-09에서 현장 D만 선택해 "CSV 내보내기" → 엑셀로 열기. 이어서 인천·공동주택으로 다시 내보내기 | D만: 제목줄 아래 데이터 1행. 인천·공동주택: 2행(A·G). 한글이 깨지지 않고, 원본 15열 뒤에 기성률·공정차이·상태·당월기성액 열이 있다(D 기성률 69.4). 범위가 없으면 "내보낼 자료가 없습니다"가 나온다. |
| 3-1 | AI 화면에서 범위와 예시 질문을 본다 | AI에게 묻기를 열고 필터를 바꿔 본다 | 상단에 현재 범위가 표시되고, 예시 질문 "D가 늦어진 원인과 대응은?", "I는 왜 점검 현장인가요?", "실제 준공일·미수금은?"과 입력창이 있다. 자료가 없으면 "자료 없음"이다. |
| 3-2 | 질문하고 근거가 붙은 답변을 받는다 | 현장 D를 선택하고 "D가 늦어진 원인과 대응은?" → "실제 준공일·미수금은?" 질문 | 첫 답변은 공급 정상화 후에도 남은 지연과 주간 확인 계획을 "기록된 상황·기록된 대응 계획"으로 설명하고, 기준 월 2026-09·현장 D·근거 숫자·참고한 기록 필드가 붙는다. 두 번째는 "자료에 없습니다"이며 계약상 준공일과 실제 완료일을 구분한다. |
| 3-3 | AI가 느리거나 실패해도 대시보드를 쓰고, 범위를 바꾸면 답변이 지워진다 | 질문 직후 필터 변경. API 키를 일부러 비운 상태에서 질문(키 값은 화면에 나오지 않음). 질문 후 CSV 내보내기·현황 페이지 이동 | 대기 중에는 "AI 답변을 기다리는 중". 범위를 바꾸면 이전 답변이 지워지고 늦게 온 응답은 새 범위에 나타나지 않는다. 실패 시 "AI 연결 실패, 대시보드와 CSV는 계속 쓸 수 있습니다"가 보이고 다른 기능은 정상이다. |
