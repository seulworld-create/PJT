# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

1. 화면 4개(현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기)에서 누르는 것마다 일어나는 일을 기능 13개로 정리했습니다.
2. 월·지역·유형·현장 필터 하나가 큰 숫자, 순위, 추이, 비교표, CSV, AI에 같은 범위로 적용됩니다.
3. 누적기성액(월말까지의 합)과 당월기성액(이번 달 누적 − 바로 전월 누적)을 구별합니다. 첫 달은 "계산 불가"입니다.
4. 오류가 나면 이유를 화면에 보여 주고, 지금 자료와 나머지 기능은 그대로 둡니다.
5. 시안은 배치와 분위기만 따르고, 숫자·현장명·열은 `data/`의 자료를 따릅니다(시안과 다른 점은 맨 아래 표).

> 교육용 가상 자료입니다. 실제 동일토건의 계약·현장·기상·사업 구성이 아닙니다.

## 4. 계산 규칙 표

| 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|
| 현장 기성률 | 누적기성액 ÷ 계약금액 × 100 | D 9월: 50,384.4 ÷ 72,600 × 100 = 69.4% |
| 현장 공정차이 | 실제공정률 − 계획공정률 (pp) | D 9월: 75.8 − 86.5 = -10.7pp |
| 상태 | 0pp 이상 정상 / -5pp 초과 0pp 미만 주의 / -5pp 이하 점검. issueCategory는 쓰지 않는다. | 계획 70·실제 70 → 정상, 65.1 → 주의, 65 → 점검. K -5.4pp → 점검 |
| 점검 우선순위 | 공정차이 오름차순, 같으면 현장 ID 오름차순 | 9월: D(-10.7) → I(-7.6) → K(-5.4) |
