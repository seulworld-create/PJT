# TRD — 현장별 공정·기성 대시보드

## 한눈에 보기

1. Next.js(화면과 서버를 한 프로젝트로 만드는 도구) + TypeScript로 만들고, 기술은 `실습조건.md`에 정해진 것만 씁니다.
2. 파일 읽기·검사·계산·CSV 만들기는 모두 브라우저에서 합니다. 서버 저장과 데이터베이스는 없습니다.
3. AI(Gemini API, 모델 `gemini-3.8-flash`)는 서버의 한 곳(`/api/ask`)에서만 호출하고, API 키는 `.env.local`에만 둡니다.
4. 계산이 맞는지는 Vitest(자동 검사 도구)로 확인하고, 정답 숫자(검산표)를 검사에 그대로 씁니다.
5. 월 비용은 0원(무료 구간)입니다. GitHub 저장·Vercel 배포는 사용자가 별도로 요청한 뒤 진행합니다.

> 교육용 가상 자료입니다. 실제 동일토건의 계약·현장·기상·사업 구성이 아닙니다.

## 1. 사용하는 기술과 고른 이유

| 항목 | 정한 것 | 고른 이유 |
|---|---|---|
| 만드는 도구 | Next.js + TypeScript | `실습조건.md`에 정해져 있습니다. 화면(브라우저)과 AI 호출용 서버를 한 프로젝트로 만들 수 있고, TypeScript는 숫자·글자 종류를 미리 검사해 계산 실수를 줄입니다. |
| 자료 처리 | 브라우저에서 파일을 읽고 계산 | 서버 저장·DB가 없다는 조건과 같습니다. 새로고침하면 자료가 사라지는 것도 이 조건에서 나옵니다. |
| 자동 검사 | Vitest | `실습조건.md`에 정해져 있습니다. 검산표 숫자(예: 9월 67.2%)를 코드로 확인합니다. |
| AI | Gemini API, 모델 `gemini-3.8-flash`, 서버에서만 호출 | `실습조건.md`에 정해져 있습니다. 서버에서만 부르면 API 키가 브라우저에 노출되지 않습니다. |
| 저장·배포 | GitHub 비공개 저장소·Vercel | `실습조건.md`에 정해져 있습니다. 실행은 사용자 별도 요청 후에만 합니다. |
| 차트 | 라이브러리 없이 화면에 직접 그림(SVG: 브라우저가 그리는 선·도형 형식) | 새 서비스·도구를 늘리지 않기 위해서입니다. 추이 선 2개와 막대만 필요합니다. (AI 결정) |
| CSV 읽기·쓰기 | 직접 만든 작은 코드 | 열이 15개로 고정이고 따옴표·쉼표 처리만 필요합니다. 검사와 함께 Vitest로 확인합니다. (AI 결정) |
| 화면 꾸미기 | Next.js에 기본으로 들어 있는 CSS 파일 방식 | 별도 도구 설치가 필요 없습니다. `design/stitch_/DESIGN.md`와 시안의 색·배치를 따릅니다. (AI 결정) |
| 페이지 사이 자료 공유 | 모든 페이지를 감싸는 한 곳(공통 틀)에 자료·필터를 보관 | 페이지를 옮겨도 가져온 자료와 필터가 유지되게 합니다(FRD F-13). 새로고침하면 사라집니다. (AI 결정) |

새로 가입해야 하는 서비스는 없습니다(GitHub·Vercel·Gemini만 사용).

## 2. 프로젝트 구조

| 위치 | 하는 일 |
|---|---|
| `src/app/` | 4개 페이지(현황 요약 `/`, 현장별 비교표 `/compare`, 자료 가져오기 `/import`, AI에게 묻기 `/ask`)와 공통 틀 |
| `src/app/api/ask/route.ts` | AI 호출 서버 코드(서버에서만 실행). 브라우저가 보낸 자료와 질문으로 Gemini를 부르고 답변을 돌려줌 |
| `src/lib/validate.ts` | 가져온 자료 검사(FRD 5번 표의 8가지 검사) |
| `src/lib/csv.ts` | CSV 읽기, 내보내기(UTF-8 BOM, 추가 4열) |
| `src/lib/calc.ts` | 기성률·공정차이·상태·가중 공정률·당월기성액·월별 추이 계산 |
| `src/lib/filter.ts` | 월·지역·유형·현장 필터와 "선택 현장이 범위에서 빠지면 전체로" 규칙 |
| `src/lib/prompt.ts` | AI에 보낼 자료 구성(원문 행과 계산값을 구분)과 지시문 |
| `src/lib/store.tsx` | 자료·필터·AI 답변을 담는 공통 보관 장소 |
| `src/components/` | 큰 숫자, 점검 순위, 추이·막대 차트, 비교표, 펼침 행, 상태 화면 등 |
| `tests/` | Vitest 자동 검사 파일 |
| `data/` | 원본 자료(고치지 않음). 앱은 파일을 사용자가 직접 가져오는 방식으로만 읽는다. |
| `.env.local` | Gemini API 키(GitHub에 올리지 않음) |

## 3. 실행 방법

| 순서 | 할 일 | 설명 |
|---|---|---|
| 1 | 설치 | `npm install` (필요한 도구를 내려받는 명령) |
| 2 | 키 넣기 | 강사가 준 Gemini API 키를 `.env.local`에 `GEMINI_API_KEY=...` 형태로 한 줄 저장 |
| 3 | 실행 | `npm run dev` 후 브라우저에서 주소(기본 `http://localhost:3000`)를 연다. 이미 쓰는 포트(접속 번호)가 있으면 다른 번호로 실행한다. 실행 중인 다른 서버는 끄지 않는다. |
| 4 | 자료 가져오기 | `data/현장공정기성.csv` 또는 `.json`을 자료 가져오기 페이지에서 고른다. |
| 5 | 자동 검사 | `npm test` (Vitest 실행) |
| 6 | 빌드 확인 | `npm run build` (배포용으로 만들어 오류가 없는지 확인) |

- 키가 없어도 대시보드·비교표·CSV는 쓸 수 있고, AI 화면만 "AI 연결 실패" 안내를 보여 줍니다(FRD F-11).
- 모의 응답(진짜 AI가 아닌 미리 만든 답): 자동 검사에서만 씁니다. 화면에 쓸 때는 "모의 응답"이라고 표시하고, 실제 AI 성공으로 기록하지 않습니다. (AI 결정)

## 4. 배포 방법 (안내만, 사용자가 별도로 요청한 뒤 진행)

| 단계 | 내용 | 누가 시작하나 |
|---|---|---|
| GitHub 저장 | 비공개 저장소에 코드를 올린다. `.env.local`은 올리지 않는다(`.gitignore`로 제외). | 사용자가 저장소 주소를 알려 주고 "이 저장소에 올려 줘"라고 요청할 때만 |
| Vercel 배포 | Vercel에서 저장소를 연결하고 환경 변수 `GEMINI_API_KEY`를 따로 등록한 뒤 배포한다. | 사용자가 STEP 11에서 직접 하거나, 프로젝트·저장소를 정해 별도로 요청할 때만 |

- GitHub 저장 요청은 Vercel 배포 요청을 포함하지 않습니다.
- 구현·검사 작업에는 저장소 생성·커밋·푸시, Vercel 프로젝트 생성·연결·환경 변수 등록·배포, 자동 배포 설정을 넣지 않습니다.

## 5. AI 모델과 키 보관 방법

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 모델 | `gemini-3.8-flash` | `실습조건.md`에 정해져 있다. |
| 호출 위치 | 서버 코드 `/api/ask`에서만 | 브라우저 코드에는 키가 들어가지 않는다. |
| 키 보관 | `.env.local`의 `GEMINI_API_KEY`. 배포 서버에서는 환경 변수로 따로 등록 | 코드·GitHub·화면·대화에 키 값을 남기지 않는다. |
| 키 노출 방지 | 키 값을 화면·로그·오류 문구에 출력하지 않는다. 오류 때는 "키가 없거나 올바르지 않습니다"만 알린다. | 키 유출 방지 |
| 보내는 자료 | 선택 월·범위의 원문 행, 프로그램이 계산한 지표, 선택 월까지의 월별 요약, 한 현장 선택 시 그 현장의 월별 기록(원문과 계산값을 구분해 전달) | FRD F-11. AI는 이 자료 밖의 내용을 답하지 않는다. |
| 지시문 | issueSummary는 "기록된 상황", actionPlan은 "계획된 대응"으로 설명. 원인·완료 여부를 만들지 않음. 계약상 준공일은 계약상 일정으로만 안내. 실제 준공일·미수금·수금액·기상 실측은 "자료에 없음" | `데이터설명.md`의 AI 범위 |
| 계산 분담 | 모든 숫자는 프로그램이 계산해서 전달한다. AI는 계산하거나 숫자를 바꾸지 않는다. | FRD 역할별 표 |
| 시간 제한·실패 | 응답 시간 제한을 두고(AI 결정: 30초), 키 없음·한도 초과·시간 초과·연결 실패를 구분해 안내한다. 대시보드·CSV는 영향을 받지 않는다. | FRD F-11 |
| 범위가 바뀔 때 | 요청마다 범위 식별값을 붙이고, 응답이 왔을 때 현재 범위와 다르면 버린다. 필터 변경 시 이전 답변도 지운다. | FRD F-12 |

## 10. 지킬 것

- `data/` 원본 파일은 고치지 않고, 실험은 사본으로 합니다.
- `.env.local`은 GitHub에 올리지 않고, API 키 값은 대화·화면·코드에 출력하지 않습니다.
- 앱 구현과 로컬 검증이 끝나면 결과를 보고하고 멈춥니다. GitHub 저장과 Vercel 배포는 사용자가 별도로 요청한 뒤 진행합니다.
